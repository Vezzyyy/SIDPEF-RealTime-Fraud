# SIDPEF - Système Intelligent de Détection et Prévention des Fraudes Monétiques en Temps Réel

Projet académique - Master Data & IA.

## Architecture du dépôt
- `data/` : Jeux de données locaux (train/test bruts ignorés par Git) et échantillons fictifs.
- `notebooks/` : Notebooks d'exploration et d'entraînement GPU (XGBoost / CUDA).
- `src/` : Scripts utilitaires et modules de prétraitement.
- `models/` : Modèles exportés (.joblib) ignorés par Git.
- `docs/` : Documentation agile (Jira, Miro, Make).
